# Chog Soul: voice, memory and a $CHOG-funded economy

Date: 2026-10-20. Status: built (see `docs/progress.md`). Lives in the same server as City and Cult (`cult/src/soul/`).

## Decisions from the user

| Question | Decision |
| --- | --- |
| Model provider | OpenRouter (OpenAI-compatible chat completions). Default model `anthropic/claude-haiku-5.5` ($0.10/M input, $0.50/M output on 2026-10-20). |
| Who talks to a Chog | Only its current holder chats. Cult debate and votes become AI-written for Chogs whose holder opts in. |
| Who pays | Holders, from a credit balance that belongs to their **wallet**, spendable on any Chog they hold. |
| Currency | **$CHOG** on Monad mainnet: `0x350035555E10d9AfAF1566AaebfCeD5BA6C27777` (listed on chog.xyz; on chain: "Chog"/CHOG, 18 decimals, EIP-1167 minimal proxy to `0x7f64…fae8`, not upgradeable, standard ERC-20 Transfer events, EIP-2612 permit). |

## How the economy works

1. **Top up.** A holder sends $CHOG from the wallet they sign in with to the project treasury address, as an
   ordinary ERC-20 transfer. No contract to deploy and nothing to approve.
2. **Credit.** The server indexes $CHOG `Transfer(from, treasury, value)` logs up to the `finalized` block,
   so a credited deposit can never be reorged away. Each log credits `from` once (unique transaction hash
   and log index). Deposits from an exchange or contract credit that sender: holders are told to send from
   the wallet they sign in with.
3. **Price list.** Every AI action has a posted price in $CHOG, set in configuration:

   | Action | Default price | Approx. model cost | Token cap |
   | --- | --- | --- | --- |
   | Chat reply | 1 CHOG (~$0.0014) | ~$0.0003 | 300 output tokens |
   | Debate line | 0.25 CHOG | ~$0.0001 | 80 output tokens |
   | Vote decision (all three places) | 0.25 CHOG | ~$0.0001 | 60 output tokens |

   A fixed list needs no price oracle and bounds the project's cost per action; prices are revised if
   $CHOG moves a lot. Every charge records OpenRouter's reported cost beside it, so margins are visible.
4. **Hold, then charge.** An action first holds its price from the balance (refused if the balance is too
   low). The model is then called outside any lock. Success turns the hold into a charge; failure,
   timeout or an invalid answer refunds it. Holders never pay for errors.
5. **Consent.** Because one balance pays for all of a holder's Chogs, each Chog has an **AI switch**
   (default off) and a **daily cap** (default 20 CHOG). Automatic actions (debate, votes) only spend when
   the switch is on and the cap allows. Chat is always an explicit holder request.
6. **Fallback.** No AI, no credits, cap reached, or provider down: the Chog speaks its scripted line and
   votes by its traits, labelled as such. The game never stops for money.
7. Credits are a prepaid service balance, not a token: no withdrawals or refunds of deposits in this
   version, which the UI states before anyone pays.

## The Soul itself

- **Persona** (no AI cost): name, temperament, talents, voice and a catchphrase, derived
  deterministically from the Chog's Genesis traits. Public on its profile.
- **Memory**: public facts the world already knows (City home, focus, recent activity; Cult faction,
  glory, recent decrees) plus a private chat history that belongs to the current holder. A sale starts a
  new private memory: the buyer never sees the seller's chats.
- **Untrusted text**: names, traits, memories and holder messages go to the model as data, and replies are
  length-capped, stripped of markup and rendered as text. A Chog has no tools in this version, so a
  prompt cannot move funds or change game state. Votes are only accepted as one of the allowed decree IDs.

## Cult with AI

At Debate, each opted-in Chog writes one argument for the decree its persona favours; at Vote it chooses
one decree per place from the allowed menu. Calls run before the scheduler takes its lock; the transition
then records the text and votes and settles the holds in the same transaction. Counting, influence and
outcomes stay rule-based. Lines are labelled `AI` or `Scripted`.

## Not in this version

Withdrawals, USDC or MON payments, x402 pay-per-request, tools or wallet actions for Chogs, public chat,
Discord (next step, on top of this).
